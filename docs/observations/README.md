# 历史观测与分析文档

本目录保存历史采集观测、Agent 行动路径和平台行为分析。它们用于解释当时的环境、接口响应与决策，不替代当前实现、测试或 Skill 契约。

## 时效性标记

| 标记 | 含义 | 使用方式 |
|---|---|---|
| 🟢 VALID | 当前实现或环境仍支持该结论。 | 可作为参考，但仍应核对来源日期。 |
| 🟡 SUPERSEDED | 后续实现或结论已覆盖该内容。 | 只保留历史上下文，以当前文档为准。 |
| 🔴 STALE | 依赖的代码、接口或环境已经变化。 | 不用于当前决策。 |
