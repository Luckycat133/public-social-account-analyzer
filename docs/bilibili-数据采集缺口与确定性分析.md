# B站公开数据采集缺口与确定性分析

本文档记录 B站公开数据接口的响应特征、风控边界与采集确定性分析。

## 核心端点与策略

1. **`medialist/resource/list`（首选路径）**
   - 特征：免 WBI 签名，直接返回完整 7 项互动指标。
   - 稳定性：高，无需逐条 `view` 补充。

2. **`arc/search`（降级 A）**
   - 特征：需要 WBI 签名（`enc_wbi`），仅包含基础视频字段。
   - 补全：需逐条调用 `web-interface/view` 补全点赞、投币、收藏、分享等互动指标。

3. **`search/type`（降级 B）**
   - 特征：仅返回 BV 号列表。
   - 补全：需逐条调用 `web-interface/view` 补全单视频详情。

## 风控与降级响应

- **`-799`**：请求频控，需增加退避等待（sleep 10s）并更换 User-Agent。
- **`-401` / `-412`**：风控人机验证或 IP 限制，停止采集并如实记录 `stop_reason`。
- **`null` 规则**：不可见或未暴露字段一律填 `null`，严禁填充 0。
