# Skill 0.7.1 自治能力与经验路径验收

## 结论

这组对照用于回答两个问题：Skill 是否仍会系统性拖累通用 Agent，以及平台经验能否在不恢复
固定流水线的前提下提高结果质量。稳定结论是：经验库版本消除了旧版的强制流程拖累；加入批量
同口径列表、直接证据链接和工具类型切换经验后，在三道补充题上略优于无 Skill 对照。

## 强制边界根因对照

9 道任务、36 项有效断言的单轮对照结果：

| 配置 | 通过断言 | 通过率 |
|---|---:|---:|
| 经验库版本 | 34/36 | 94.4% |
| 旧版强制流程 Skill | 21/36 | 58.3% |
| 无 Skill | 34/36 | 94.4% |

旧版主要问题是把四个层级混在一起：安全边界、证据边界、正式制品合同和 Agent 编排。不可变
目录、完整 taxonomy、固定输出和 `delivery_ready` 本应只约束正式制品，却被扩张成所有聊天
任务的前置条件，导致模糊范围自动全量、局部失败抹去有效证据、搜索只能作为末级降级，以及
小样本完全禁答。

修正后的原则是“约束主张，不约束思考”：身份与证据真实性仍然严格；工具顺序、样本扩张、
是否生成文件和何时停止由用户目标及证据充分性决定。`PARTIAL`、适配器失败或渲染失败不再
自动翻译为整个用户任务失败。

## 高收益经验补充对照

3 道任务、15 项断言的后续单轮对照结果：

| 配置 | 通过断言 | 通过率 |
|---|---:|---:|
| 加入高收益路径经验的候选版 | 15/15 | 100% |
| 前一轮经验库候选版 | 13/15 | 86.7% |
| 无 Skill | 14/15 | 93.3% |
| 更早的强制流程版本 | 6/15 | 40.0% |

有效改动不是增加限制，而是给出更高收益的经验：B站优先 `card → 投稿列表 → medialist → 动态补缺`；
YouTube 等平台优先 RSS/Feed；快速任务先争取约 10–20 条同口径记录；搜索页只发现线索，账号
结论绑定直接作品 URL 或稳定 ID。三道候选运行分别取得 B站 20 条、20 条和 YouTube 15 条
同口径数据，避免了只拿 3–4 条个案或在等价端点间漫游。

## 适用限制

- 两组质量对照每个配置每题只运行一次，不能估计模型方差。
- 执行器没有提供可复核 token 数据，墙钟记录也不一致，因此不据此声称成本优势。
- 第一组协议缺少完整的重复次数与 timing 元数据，只能作为设计根因证据，不能作为严格性能基准。
- 当前触发稳定性另见 [`skill-trigger-0.7.1.md`](skill-trigger-0.7.1.md)；报告可读性另见
  [`human-report-0.7.2.md`](human-report-0.7.2.md)。
