# Test 留出数据集

`test_data/` 是从 `source/` 生成的最终留出验收集。它用于版本候选、发布或里程碑验收，不用于日常开发调参。

## 使用边界

- 仅在预先定义的验收节点运行；
- 运行前冻结代码、提示词和评估规则；
- 记录数据版本、manifest SHA、代码版本、执行时间和聚合结果；
- 只报告整体或预先定义分组结果，避免针对单条测试样本反复调优。

## 失败处理

测试失败时先识别可泛化的根因。若需要增加覆盖，应在 `source/` 新增独立场景、更新 CHANGELOG 并重新划分；不得复制测试记录到 validation，不得直接修改测试答案后继续报告原版本结果。

## 禁止事项

- 不得手工修改本目录文件；
- 不得用测试提示逐条调参；
- 不得与 `validation_data/` 共享 ID；
- 不得加入 source 外记录；
- 不得保存凭证、私有后台数据或个人敏感信息。

## 完整性验证

```bash
python3 skill/scripts/split_dataset.py --verify
```

字段、来源与划分策略见上级 [README](../README.md)，正式运行流程见 [USAGE](../USAGE.md)。
