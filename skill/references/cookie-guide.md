# Cookie 获取与对话粘贴

适用于本技能中需要登录会话的所有目标平台。Agent 根据当前任务网址判断目标站点，并按当前采集器支持的 Cookie 参数完成交接；不为每个平台重复一套获取说明。

## Agent 引导规则

- 登录墙出现时，先用自己的自然语言简短解释：需要用户的网页登录状态才能继续读取当前账号可见内容，以及这会带来的会话访问风险。只说明一次，不展开安全教育。
- 让用户在**当前目标平台**的电脑浏览器正常登录后，按 `F12`（macOS：`⌥⌘I`）打开 **Network/网络**，刷新页面。
- 引导用户从当前站点请求的 **Headers/标头** → **Request Headers/请求标头** 复制完整 `Cookie: ...` 一行，并直接粘贴到对话。
- 面向用户只给当前最短的可行下一步，不把回复组织成“不要文件、截图或单个 Cookie 值”等禁止清单。用户已经粘贴后直接尝试采集，不再次解释风险或要求重复确认。

## 备用：导出 JSON

Network 面板没有 Cookie 行时，才让用户使用能导出当前站点 JSON 的 Cookie 扩展：登录目标站点 → 打开扩展 → 选择当前域名 → **Export JSON** → 将完整 JSON 粘贴到对话。

手机 App 和多数手机浏览器不适合该流程；只有手机时，说明需要一台电脑浏览器才能完成标准交接，并继续提供公开样本路径。不要为此展开其他绕路或替代方案。

## Agent 交接规则

Agent 接收完整 `Cookie: name=value; ...` 请求头或 JSON 后，以任务期临时文件交给当前采集器；命令行只传临时路径。解析器可接受 `Cookie:` 前缀、普通 `name=value; ...` 文本、JSON 数组与简单 JSON 对象；具体参数和平台域名校验以对应平台参考及 `scripts/README.md` 为准。

Agent 不在回复、报告、工作区或命令行中复述 Cookie 原文；完成或中断后删除临时文件。

## 失败时的处理

| 情况 | Agent 行为 |
| --- | --- |
| 仍提示登录 | 指导用户刷新已登录页面后复制新的完整请求头。 |
| 触发验证码或滑块 | 说明用户需在浏览器完成验证后重新复制；仍受限时回到当前可见样本。 |
| 格式或域名不匹配 | 说明必须复制当前平台页面请求的完整 Cookie 行。 |
