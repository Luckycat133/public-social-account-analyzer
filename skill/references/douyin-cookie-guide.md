# 抖音 Cookie 文件：面向用户的简明指引

仅在用户明确表示“这是我自己的抖音登录会话”或“我有权使用这个会话”时使用本指引。Cookie 相当于临时登录钥匙：不要让用户把内容粘贴到聊天、邮件、截图、命令行或代码仓库；只让用户在本机保存文件，并通过当前任务允许的本机文件选择器或文件路径提供该文件。

本指引只用于让采集器读取用户在网页上本来能看到的内容。它不适用于他人的会话，不处理验证码/滑块，不指导从抖音 App、手机备份、浏览器数据库或远程调试中提取 Cookie。

## Agent 的引导方式

先用一句话说明目的和边界：

> 如果你愿意，可在你自己的电脑浏览器登录抖音后导出一个本地 Cookie 文件；请不要把 Cookie 文本发到聊天里。这个文件只会用于读取你本来可见的抖音页面，遇到验证码仍会停止。

再让用户按设备选一条路径。一次只给所选设备的步骤；不要把所有设备步骤同时堆给用户。

## Windows 或 macOS：Chrome、Edge、Brave、Arc、Opera

这是推荐路径。需要一台电脑和用户自己的浏览器登录状态。

1. 在电脑打开浏览器，进入 `https://www.douyin.com/`，确认已登录自己的账号。
2. 打开该浏览器的**官方扩展商店**，搜索“Cookie export”或“Cookie editor”。选择能将当前网站 Cookie 导出为 **JSON**、不要求登录或云同步的扩展；安装前先阅读权限说明。
3. 回到已经登录的抖音网页，点击扩展图标，选择当前网站或 `douyin.com`，点击 **Export JSON / 导出 JSON**。
4. 将文件保存为 `douyin-cookies.json`，放在自己容易找到的位置，例如“下载”文件夹。不要打开文件复制内容。
5. 回到当前任务，只提供该文件的本机路径或在文件选择器中选择该文件；不要把文件内容贴进聊天。
6. 完成分析后，若不再需要，删除该文件并移除刚安装的导出扩展。

如果扩展界面没有“JSON”选项，停止在这一步，让 Agent 改走公开证据/样本路径；不要改为复制浏览器开发者工具中的 Cookie 值。

## Windows、macOS 或 Linux：Firefox

1. 在 Firefox 打开 `https://www.douyin.com/`，确认已登录自己的账号。
2. 在 Firefox Add-ons 官方页面搜索“Cookie export”或“Cookie editor”，选择可导出当前网站 **JSON**、不要求云同步的扩展，并阅读权限说明。
3. 回到抖音标签页，打开扩展，选择 `douyin.com`，使用 **Export JSON / 导出 JSON**。
4. 保存为 `douyin-cookies.json`；不要复制或发送文件内容。
5. 通过当前任务的本机文件选择器或文件路径提供文件。用完删除文件和扩展。

## 只有 iPhone、iPad 或 Android 手机

手机抖音 App 和大多数手机浏览器没有适合本工作流的安全、稳定 Cookie 导出方式。

1. 不要尝试从 App、手机备份、文件系统、Root/Jailbreak 工具或远程调试中提取 Cookie。
2. 如有电脑，在电脑浏览器打开 `https://www.douyin.com/`，使用自己的账号登录，再按上面的电脑浏览器步骤导出。
3. 没有电脑或不愿导出时，告诉 Agent 继续使用无需登录的公开证据、用户提供的公开视频链接，或将结果明确标为样本观察。

## 导出后交给 Agent 的最少信息

用户只需提供：Cookie 文件的本机路径，或在受支持的文件选择器中选中 `douyin-cookies.json`。不要提供 Cookie 文本、截图、密码、短信验证码、扫码登录页面或浏览器同步账号。

Agent 仅把**文件路径**传给：

```bash
python3 scripts/collect_douyin_complete.py \
  "https://www.douyin.com/user/<sec_uid>" \
  --douyin-cookie-file /path/to/douyin-cookies.json \
  --out-prefix workspace/douyin-user-session
```

采集器接受常见浏览器扩展导出的 JSON Cookie 数组；也接受简单 JSON 对象或 Cookie header 文本，但用户引导默认只推荐 JSON。文件只允许 `douyin.com` 及其子域，且不会写入工作区、报告或日志。

## 常见情况

| 用户看到的情况 | Agent 应如何回应 |
| --- | --- |
| 网页仍提示登录 | 请用户在电脑浏览器完成自己的正常登录后重新导出；不要索要密码或验证码。 |
| 出现滑块/安全验证 | 停止；说明采集器不会绕过验证，可改用公开样本或稍后由用户正常完成验证后再试。 |
| 导出的不是 JSON | 请用户在扩展里选择 JSON；没有该选项则不接收 Cookie 内容，改走公开路径。 |
| 文件报过大、格式或域名错误 | 让用户重新从当前 `douyin.com` 标签页导出 JSON；不要请用户打开文件手工修改。 |
| 用户不确定是否有权使用会话 | 不请求文件；继续匿名公开研究或请用户提供公开作品链接。 |

## Agent 禁止事项

- 不要求、记录、回显或转发 Cookie 值。
- 不建议导出他人会话、共享账号会话或企业设备中不属于用户的会话。
- 不指导 Root、Jailbreak、浏览器数据库解密、远程调试、抓包、代理、伪造签名或绕过验证码。
- 不把 Cookie 成功读取等同于全量证据；仍按实际分页、账号绑定和末页证据决定 `PARTIAL` 或穷尽性。
